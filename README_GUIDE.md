## 📁 1. ಈ ಫೋಲ್ಡರ್‌ನಲ್ಲಿರುವ ಫೈಲ್‌ಗಳ ಪಟ್ಟಿ (File Directory)

1. **`index.html`**  
   - ವಾಯ್ಸ್ ಸ್ಟುಡಿಯೋದ ಕಂಪ್ಲೀಟ್ 100 ಧ್ವನಿಗಳ ವೆಬ್‌ಸೈಟ್ ಡಿಸೈನ್ ಮತ್ತು ಶೀರ್ಷಿಕೆ ಪೇಜ್.
2. **`style.css`**  
   - ಪ್ರೀಮಿಯಂ ಡಾರ್ಕ್ ಥೀಮ್, ಕಾಂಪ್ಯಾಕ್ಟ್ ಕಾರ್ಡ್‌ಗಳು ಮತ್ತು ಸುಂದರ ಬಣ್ಣಗಳ ವಿನ್ಯಾಸ ಫೈಲ್.
3. **`app.js`**  
   - 100 ಧ್ವನಿಗಳ ಮಾದರಿ ಮಾತುಗಳು, ಫ್ಲೋ ಸ್ಟೈಲ್ಸ್ ಮತ್ತು ವೆಬ್ ಆಡಿಯೋ ಇಕ್ವಲೈಸರ್ ಸೌಂಡ್ ಇಂಜಿನ್.
4. **`server.js`**  
   - ಕನ್ನಡ ಆಡಿಯೋ ಪ್ರೊಸೆಸಿಂಗ್, ಇಂಗ್ಲಿಷ್-ಟು-ಕನ್ನಡ ಫೋನೆಟಿಕ್ ಮತ್ತು ಬ್ರ್ಯಾಕೆಟ್ `(...)` ಸ್ಕಿಪ್ ಫಿಲ್ಟರ್ ಇರುವ ಪ್ರಮುಖ ಸಾಫ್ಟ್‌ವೇರ್ ಫೈಲ್.
5. **`package.json`**  
   - ಕ್ಲೌಡ್ ಸರ್ವರ್ ರನ್ ಆಗಲು ಬೇಕಾದ ಎಕ್ಸ್‌ಪ್ರೆಸ್ ಲೈಬ್ರರಿ ಫೈಲ್.
6. **`mahiti-chakra-voice-studio.php`**  
   - ನಿಮ್ಮ Hostinger WordPress ಗೆ 1-ಕ್ಲಿಕ್‌ನಲ್ಲಿ ಆಟೋಮ್ಯಾಟಿಕ್ ಆಗಿ ಪೇಜ್ ಸೇರಿಸಲು ರೆಡಿ ಪ್ಲಗಿನ್ ಫೈಲ್.
7. **`README_GUIDE.md`**  
   - ಪ್ರಸ್ತುತ ನೀವು ಓದುತ್ತಿರುವ ಕಂಪ್ಲೀಟ್ A to Z ಮಾರ್ಗದರ್ಶಿ.

## 🚀 2. ಮುಂದಿನ ಉಚಿತ ಕ್ಲೌಡ್ & Hostinger ಸೆಟಪ್ ಹಂತಗಳು (3 Simple Steps)

### **ಹಂತ 1: GitHub ಗೆ ಅಪ್‌ಲೋಡ್ ಮಾಡುವುದು (1 Minute)**
1. **[GitHub.com](https://github.com)** ಗೆ ಉಚಿತವಾಗಿ ಲಾಗಿನ್ ಆಗಿ.
2. **`New Repository`** ಕ್ಲಿಕ್ ಮಾಡಿ, ಹೆಸರನ್ನು `Kannada_Pro_Studio` ಎಂದು ನೀಡಿ.
3. ಈ ಡೆಸ್ಕ್‌ಟಾಪ್ ಫೋಲ್ಡರ್‌ನಲ್ಲಿರುವ ಫೈಲ್‌ಗಳನ್ನು ಅಲ್ಲಿಗೆ ಅಪ್‌ಲೋಡ್ ಮಾಡಿ **`Commit`** ಕೊಡಿ.

### **ಹಂತ 2: Render.com 24/7 ಉಚಿತ ಕ್ಲೌಡ್ ಸರ್ವರ್ ಸೆಟಪ್ (1 Minute)**
1. **[Render.com](https://render.com)** ಗೆ ಲಾಗಿನ್ ಆಗಿ `New Web Service` ಕ್ಲಿಕ್ ಮಾಡಿ.
2. ನಿಮ್ಮ GitHub Repository ಆಯ್ಕೆ ಮಾಡಿ `Deploy` ಕೊಡಿ.
3. 30 ಸೆಕೆಂಡಿನಲ್ಲಿ ನಿಮಗೆ **`https://mahiti-voice-studio.onrender.com`** ನಂತಹ ಉಚಿತ ಲೈವ್ ಲಿಂಕ್ ಸಿಗುತ್ತದೆ!

### **ಹಂತ 3: Hostinger (mahitichakra.in) ವೆಬ್‌ಸೈಟ್‌ಗೆ ಹಾಕುವುದು**
ನಿಮ್ಮ WordPress Admin `mahitichakra.in/wp-admin` ಗೆ ಲಾಗಿನ್ ಆಗಿ `Pages ➔ Add New` ಕ್ಲಿಕ್ ಮಾಡಿ ಈ 1 ಸಾಲಿನ ಐಫ್ರೇಮ್ ಕೋಡ್ ಹಾಕಿ ಪಬ್ಲಿಷ್ ಕೊಡಿ:
